# שבצ״ק על אנדרואיד

אותו מבנה כמו באייפון: הממשק הוא אפליקציית הווב שכבר עובדת, רצה בתוך `WebView`. מה שהאפליקציה מוסיפה זה ווידג׳ט במסך הבית, התראות דרך Firebase, ואייקון בתפריט.

בונים על שרת של גיטהאב. אנדרואיד נבנה על לינוקס, אז זה מהיר וזול, ולא צריך שום מחשב מיוחד.

הווידג׳ט והתראות משתמשים בדיוק באותן נקודות קצה שנבנו לאייפון, `‎/api/widget` ו־`‎/api/notify/ext`. אין כאן שרת שני.

---

## מה יש כאן

| קובץ | מה זה |
|---|---|
| `app/src/main/java/.../MainActivity.kt` | המעטפת. פותחת את האתר, מקבלת את אסימון הווידג׳ט מהדף. |
| `.../ShavtzakWidget.kt` | הווידג׳ט. שואל את השרת מה הדבר הבא, ומצייר. |
| `.../Push.kt` | ההתראות. Firebase מביא הודעה ריקה, וזה מושך את הטקסט האמיתי. |
| `.../Shared.kt` | האסימון, הכתובת, והתשובה האחרונה. |
| `../.github/workflows/android.yml` | הבנייה. |

הווידג׳ט לא יודע עברית ולא מחשב תאריכים, בדיוק כמו באייפון. השרת שולח משפטים גמורים והוא מצייר אותם. שינוי נוסח נעשה בשרת ומגיע לכולם מיד, בלי לחכות לעדכון בחנות.

הספירה לאחור היא `Chronometer` של אנדרואיד, שרץ לבד. אנדרואיד לא מרשה לווידג׳ט לפנות לרשת יותר מפעם בחצי שעה, אז דקות חיות חייבות לבוא מהשעון של המכשיר ולא מהשרת.

---

## מה צריך להכין

### 1. הכתובת

בגיטהאב, Settings ← Secrets and variables ← Actions ← **Variables** ← משתנה בשם `SH_ORIGIN`, והערך הוא הכתובת של האפליקציה בלי לוכסן בסוף.

### 2. מפתח חתימה

צור אותו במחשב שלך פעם אחת, ושמור אותו במקום בטוח. אם הוא הולך לאיבוד אי אפשר לעדכן את האפליקציה בחנות לעולם.

```
keytool -genkeypair -v -keystore upload.jks -keyalg RSA -keysize 2048 \
        -validity 10000 -alias upload
base64 -i upload.jks | tr -d '\n'
```

### 3. Firebase

צור פרויקט ב־[console.firebase.google.com](https://console.firebase.google.com), הוסף אפליקציית אנדרואיד עם שם החבילה `com.shavtzak.app`, והורד את `google-services.json`.

באותו פרויקט: Project settings ← Service accounts ← Generate new private key. יורד קובץ JSON. הוא הולך ל־Cloudflare, לא לגיטהאב:

```
npx wrangler secret put FCM_SERVICE_ACCOUNT     # כל תוכן הקובץ, כמו שהוא
```

### 4. סודות בגיטהאב

Settings ← Secrets and variables ← Actions ← Secrets:

| שם | מה שמים |
|---|---|
| `ANDROID_KEYSTORE_B64` | ה־keystore מקודד base64 |
| `ANDROID_KEYSTORE_PASSWORD` | הסיסמה שבחרת |
| `ANDROID_KEY_ALIAS` | `upload` |
| `ANDROID_KEY_PASSWORD` | הסיסמה של המפתח |
| `GOOGLE_SERVICES_JSON` | תוכן `google-services.json` |
| `PLAY_SERVICE_ACCOUNT_JSON` | רק בהמשך, להעלאה אוטומטית |

## לבנות

Actions ← Android ← Run workflow.

בסוף יש שני קבצים להורדה. ה־`.apk` נועד להתקנה ישירה על מכשיר, כדי לבדוק מיד. ה־`.aab` הוא מה שמעלים לחנות.

---

## החנות

חשבון מפתח פרטי עולה 25 דולר חד פעמי.

**הדבר החשוב לדעת מראש:** חשבון פרטי שנפתח אחרי נובמבר 2023 חייב לעבור בדיקה סגורה לפני שאפשר לפרסם לכולם. צריך **12 בודקים שונים** שנשארו רשומים **14 יום ברצף**. אם מישהו יוצא באמצע, הספירה מתחילה מהתחלה. חשבון ארגוני פטור מזה.

בפועל זה אומר שכדאי להתחיל את השעון עכשיו: פתח חשבון, העלה בילד ראשון למסלול closed testing, ותשלח את קישור ההצטרפות ל־12 אנשים ביחידה. בזמן שהם רשומים אפשר להמשיך לעבוד. אחרי שבועיים מגישים לייצור.

את הבילד הראשון של אפליקציה חדשה חייבים להעלות ידנית דרך הקונסולה. אחרי זה אפשר להדליק את `publish` וההעלאות הבאות יקרו לבד.

**יעד API.** גוגל דורשת שאפליקציות חדשות יכוונו ל־Android 16, כלומר API 36, החל מ־31 באוגוסט 2026. הפרויקט כבר מכוון לשם, אז זה מסודר.

## תקלות נפוצות

**מסך לבן** ← המשתנה `SH_ORIGIN` לא הוגדר או לא נכון.

**הווידג׳ט אומר "לא מחובר"** ← האסימון עוד לא עבר. פותחים את האפליקציה פעם אחת אחרי התחברות.

**הווידג׳ט לא מתעדכן** ← אנדרואיד מגביל לחצי שעה. הוא מתעדכן גם בכל פתיחה של האפליקציה ובכל התראה.

**התראות לא מגיעות** ← בדוק ש־`google-services.json` נמצא בסודות, ושהסוד `FCM_SERVICE_ACCOUNT` הועלה ל־Cloudflare. שים לב שיצרן המכשיר, במיוחד שיאומי וואווי, נוטה להרוג אפליקציות ברקע. בהגדרות הסוללה צריך להוציא את האפליקציה מהאופטימיזציה.
