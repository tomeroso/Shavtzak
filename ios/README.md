# שבצ״ק על אייפון

אפליקציה אמיתית עם ווידג׳ט, בלי מק.

הממשק עצמו הוא אותה אפליקציית ווב שכבר עובדת, רצה בתוך `WKWebView`. מה שהאפליקציה מוסיפה הוא שלושת הדברים שדפדפן לא יכול לתת: ווידג׳ט במסך הבית, התראות שמגיעות דרך אפל, ואייקון משלה.

הכל נבנה על מק של גיטהאב. אתה רק לוחץ על כפתור.

---

## מה יש כאן

| קובץ | מה זה |
|---|---|
| `project.yml` | הגדרת הפרויקט. XcodeGen בונה ממנה את קובץ ה־Xcode. |
| `App/` | המעטפת. פותחת את אתר האפליקציה, נרשמת להתראות, מעבירה אסימון לווידג׳ט. |
| `Widget/` | הווידג׳ט. קטן, בינוני, ורצועה במסך הנעילה. |
| `Notify/` | תוסף שכותב מחדש כל התראה רגע לפני שהיא מוצגת. |
| `Shared/` | הדבר היחיד ששלושתם חולקים: המודל והפנייה לשרת. |
| `../.github/workflows/ios.yml` | הבנייה על מק של גיטהאב. |

---

## למה זה בנוי ככה

**הווידג׳ט לא יודע עברית ולא יודע לחשב תאריכים.** השרת שולח לו משפטים גמורים, והוא מצייר רק את הספירה לאחור. הסיבה פשוטה: כל כלל שנכתוב פעמיים ייפרד לשתי גרסאות, ואת הגרסה שבתוך האפליקציה אי אפשר לתקן בלי עוד שבוע של בדיקה אצל אפל. שינוי נוסח נעשה בשרת, ומגיע לכולם באותו רגע.

**שמות ושעות לא עוברים דרך אפל.** ההתראה שאפל מעבירה מכילה שתי מילים, "יש עדכון". התוסף שב־`Notify/` רץ שנייה לפני שהבאנר מופיע, מושך את הטקסט האמיתי מהשרת שלנו, ומחליף. זה בדיוק מה שגרסת הדפדפן עושה כבר היום, ולא ויתרנו על זה בשביל האפליקציה.

**לווידג׳ט יש אסימון משלו.** לא הסשן. הוא מגיע רק לנקודת קצה אחת, מחזיר שורה אחת של טקסט, ואפשר לבטל אותו לבד בלי להוציא אף אחד מהאפליקציה.

## מה צריך להכין, פעם אחת

### 1. השורה שחייבים לשנות

ב־`project.yml`, שנה את `SH_ORIGIN` לכתובת האמיתית של האפליקציה. אותה כתובת שאתה פותח בדפדפן, בלי לוכסן בסוף.

```yaml
SH_ORIGIN: https://shavtzak.השם-שלך.workers.dev
```

בלי זה האפליקציה תיפתח על מסך ריק.

### 2. באתר של אפל (developer.apple.com)

ב־Certificates, Identifiers & Profiles:

**App Groups** ← הוסף `group.com.shavtzak.app`

**Identifiers** ← צור שלושה App IDs:

| Bundle ID | הרשאות |
|---|---|
| `com.shavtzak.app` | App Groups, Push Notifications |
| `com.shavtzak.app.widget` | App Groups |
| `com.shavtzak.app.notify` | App Groups |

בכל אחד, בתוך App Groups, סמן את הקבוצה שיצרת.

**Keys** ← צור מפתח חדש עם Apple Push Notifications service (APNs). מורידים קובץ `.p8` **פעם אחת בלבד**. שמור אותו. רשום גם את ה־Key ID.

רשום גם את ה־**Team ID** שלך, מופיע בפינה למעלה.

### 3. ב־App Store Connect

צור אפליקציה חדשה, Bundle ID `com.shavtzak.app`, שם ושפה ראשית עברית.

Users and Access ← Integrations ← App Store Connect API ← צור מפתח בתפקיד **App Manager**. גם כאן יורד `.p8` פעם אחת. רשום את ה־Key ID ואת ה־Issuer ID.

### 4. סודות ב־GitHub

Settings ← Secrets and variables ← Actions:

| שם | מה שמים |
|---|---|
| `APPLE_TEAM_ID` | ה־Team ID |
| `ASC_KEY_ID` | ה־Key ID של מפתח App Store Connect |
| `ASC_ISSUER_ID` | ה־Issuer ID |
| `ASC_KEY_P8` | קובץ ה־p8 של App Store Connect, מקודד base64 |

להמרה לbase64: `base64 -i AuthKey_XXXX.p8 | tr -d '\n'`

### 5. סודות ב־Cloudflare

זה מפתח ה־APNs, לא זה של App Store Connect:

```
npx wrangler secret put APNS_KEY_P8      # תוכן קובץ ה-p8 כמו שהוא, כולל שורות ה-BEGIN וה-END
npx wrangler secret put APNS_KEY_ID
npx wrangler secret put APNS_TEAM_ID
```

## לבנות

Actions ← iOS ← Run workflow.

הבנייה לוקחת בערך עשר דקות. בסוף היא מעלה ל־App Store Connect לבד, והבילד מופיע ב־TestFlight תוך כמה דקות.

מספר הבילד עולה לבד בכל הרצה, כך שאין התנגשויות.

אם אתה רק רוצה לראות שזה מתקמפל בלי להעלות, כבה את `upload` בטופס.

## מ־TestFlight לחנות

תמיד עוברים דרך TestFlight, גם כשהיעד הוא החנות. תתקין על עצמך, תוודא שהווידג׳ט מתעדכן ושהתראה מגיעה, ורק אז תגיש.

לפני הגשה לחנות תצטרך:

- צילומי מסך של אייפון 6.7 אינץ׳
- תיאור בעברית, מילות מפתח, וקטגוריה. Utilities מתאים.
- קישור למדיניות פרטיות. יש כבר אחת בכתובת `/privacy.html` באפליקציה שלך.
- **חשבון הדגמה**. בלי זה יחזירו לך את ההגשה. הבודק באפל צריך להיכנס ולראות שבצ״ק, והוא לא יכול להתחבר לגוגל שלך ולא לראות שמות אמיתיים של אנשי היחידה. הדרך הנקייה היא לבנות שבצ״ק חדש בתוך האפליקציה עם שמות מומצאים, לייצר לו קישור קבוצתי ארוך טווח, ולתת לאפל את הקישור בשדה Notes.

שני דברים שכדאי לדעת מראש, כדי לא להיות מופתע:

**כלל 4.2, "מינימום פונקציונליות".** אפל דוחה אפליקציות שהן רק אתר בתוך מסגרת. הווידג׳ט, ההתראות ותוסף ההתראות הם בדיוק מה שמוציא אותנו מהקטגוריה הזאת, וכדאי לומר את זה במפורש בשדה ההערות לבודק.

**כלל 4.8, "התחברות עם אפל".** מי שמציע התחברות עם גוגל חייב בדרך כלל להציע גם התחברות עם אפל. יש חריג למי שנכנס לחשבון שלו אצל ספק חיצוני כדי להגיע לתוכן שלו, וזה בדיוק המקרה כאן, כי ההתחברות לגוגל היא מה שנותן גישה לגיליון. יכול להיות שיקבלו את זה ויכול להיות שלא. אם ידרשו, זו עבודה נוספת בשרת.

## תקלות נפוצות

**מסך לבן** ← `SH_ORIGIN` לא נכון, או שהאפליקציה לא פרוסה.

**הווידג׳ט אומר "לא מחובר"** ← האסימון עוד לא עבר. פותחים את האפליקציה פעם אחת אחרי התחברות, והוא נשמר.

**הווידג׳ט תקוע על מספר ישן** ← זה נורמלי, אפל מחליטה מתי ווידג׳ט רשאי לפנות לרשת. הוא מתעדכן כשהמשמרת מתחילה, כשהיא נגמרת, ובכל התראה שמגיעה.

**התראות לא מגיעות** ← קודם בדוק שהסודות של APNs נמצאים ב־Cloudflare. בילד של TestFlight מדבר עם שרת ה־sandbox של אפל ובילד מהחנות עם שרת הייצור, והאפליקציה אומרת לשרת באיזה משניהם היא נמצאת, כך שזה אמור להסתדר לבד.
